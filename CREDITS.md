# Source and asset credits

- Astra Game Center's layout, brand mark and web adaptation were developed for this collection with Codex. The existing English desktop interface and its existing covers were carried over.
- The game covers were created with Codex Image Generation.
- Wardenfall is the collection's original Canvas tower-defense game. Its hand-painted maps, units, walking frames and tower atlas were created with Codex Image Generation. Its English dialogue, sampled effects and woodland/stream recordings were created with ElevenLabs. Generation credentials and raw service responses are not distributed.
- `docs/wardenfall-source-manifest.json` records the original relative paths, byte sizes and SHA-256 hashes of the 35 allowlisted runtime files. The web copy changes account-specific save/audio keys, adds the authenticated loader and the return-to-collection link. Gameplay rules remain unchanged.
- Sidewalk Session adapts [threejskate by LaloMorales](https://github.com/lalomorales22/threejskate) under MIT, and [Kenney Mini Skate](https://kenney.nl/assets/mini-skate) under CC0. The original license, Kenney notice, and licenses for Three.js, crashcat and mathcat are included alongside the runtime. The custom Westside park was produced in Blender; sounds are synthesized in the game.
- Sunset Block includes the collection’s Blender city and district, CC0 MakeHuman character adaptations, [Poly Haven](https://polyhaven.com) surface textures and Kloppenheim 06 Pure Sky environment, and ElevenLabs sound/radio assets. Its sports car derives from the Three.js r180 [Ferrari car example](https://threejs.org/examples/webgl_materials_car.html), credited there to [vicent091036](https://sketchfab.com/models/57bf6cc56931426e87494f554df1dab6). The original model’s independent redistribution/license terms have not been verified; the Three.js code license should not be interpreted as proof of a separate model license. No claim of ownership or affiliation with Ferrari is made.
- Pine Hollow packages the current trail/cabin/campfire/fishing demo. It uses the collection’s Blender environment and character adaptations, CC0 MakeHuman/Poly Haven source material, Codex-generated artwork and ElevenLabs effects/ambience. The separate older survival prototype is not included.
- The Three.js r180 license is retained in both Sunset and Pine vendor folders. `docs/runtime-source-manifest.json` records source-relative paths, sizes and hashes of the original runtime assets before the documented web adaptations.
- Mario’s catalog card and generated cover were removed on 13 September 2026. Its local source project remains outside this repository.
- Next.js, React and Supabase dependencies retain their own licenses and notices in the installed packages. This repository does not declare an additional open-source license for the collection's code or artwork.

Sunset S06 adds the collection’s original Blender waterfront, bridge leaves and gates, harbor boat, terminal and airliner. Traffic reuses colored versions of the existing sports-car LOD. Existing asset credits and their limitations continue to apply. `docs/sunset-release-manifest.json` records source and packaged hashes for the 60 shipped files.
